# Software Versions

- Use latest stable versions of apps, packages, tools, actions, and other software unless instructed otherwise.
- Prefer installers/selectors that automatically resolve latest stable; skip separate version checks when using them.
- Before adding/changing any other version selector—including pins and GitHub Actions `uses` refs—verify against an authoritative source that it targets the latest stable release.

# Attribution

- Never add attribution, authorship, provenance, or generated-by notices to text, code, comments, or documentation.
