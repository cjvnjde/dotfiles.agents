# Questions and Actions

- Answer questions without taking action, especially when labelled "question" or "just asking". Read-only inspection is allowed.
- For mixed requests, make only explicitly requested changes; answer the rest.

# Software Versions

- Use latest stable software unless instructed otherwise.
- Prefer installers that resolve latest stable automatically; skip redundant version lookups.
- Otherwise, verify version selectors, including pins and GitHub Actions refs, against authoritative sources.

# System-wide Software Installation

- Use mise for global development tools; keep project dependencies local. Explain unsupported installs before choosing an alternative.
- For other software, follow official upstream guidance; prefer the platform's standard package manager and official repositories when supported.
- Verify package identity, source, and available integrity checks. Stop on failed checks; obtain approval for unofficial or unverifiable alternatives.
- Smoke-check installations and report the method, source, and verification.

# Attribution

- Never add attribution, authorship, provenance, or generated-by notices to text, code, comments, or documentation.
